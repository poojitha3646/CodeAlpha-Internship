# CodeAlpha-Internship
1. Hangman Game
==================================================
 Description

Hangman Game is a simple text-based Python project where the player tries to guess a hidden word one letter at a time. The game randomly selects a word from a predefined list, and the player has a limited number of attempts to guess it correctly.

If the guessed letter is present in the word, it is revealed. If the guessed letter is incorrect, the number of attempts decreases. The game continues until the player either guesses the complete word or runs out of attempts.

 Features

* Random word selection
* Letter-by-letter guessing
* Input validation
* Limited attempts
* Win and lose conditions
* User-friendly interface

Technologies Used

* Python

2. Smart Chatbot
 =============================================================
 Description

Smart Chatbot is a simple rule-based chatbot developed using Python. The chatbot interacts with users by responding to predefined keywords and questions. It provides appropriate responses based on the user's input and continues the conversation until the user chooses to exit.


 Features

* Interactive conversation
* Keyword-based responses
* User-friendly interface
* Handles multiple types of questions
* Exit option using 'bye'

 Technologies Used

* Python
